# Musafir Gateaways — premium frontend website

A responsive static website inspired by the new blue/white/orange travel concept.

## Included
- `index.html` — homepage and package detail dialog
- `styles.css` — responsive styling
- `script.js` — package popups, enquiry search and WhatsApp messages
- `assets/` — company logo

## Publish using GitHub Pages
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload the contents of this folder (not the outer folder) to the repository root.
4. Open repository **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. Once deployed, add your custom domain in the Pages settings and configure DNS at your domain provider following GitHub's instructions.

## Important
This is frontend-only. It has no backend, database, payment gateway, booking engine or admin panel. Enquiries are sent to WhatsApp with pre-filled details. Package descriptions are sample inspiration; confirm prices, dates, itinerary and availability directly with the company. Destination photos and Google Fonts are loaded from external services and require internet access.
